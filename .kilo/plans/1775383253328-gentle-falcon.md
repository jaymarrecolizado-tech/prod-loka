# Gas Voucher Signatory Routing Plan

## Overview
Allow approvers to select specific signatories from dropdown lists when processing gas vouchers:
- **Reviewed by** → Select from active users with `ROLE_MOTORPOOL` (motorpool head)
- **Approved by** → Select from active users with `ROLE_CHIEF_ADMIN_FINANCE` (Chief Admin & Finance)

These selections will be stored in the `gas_vouchers` table's `reviewed_by` and `approved_by` columns instead of auto-assigning to the logged-in user.

## Current State
- `approve.php` currently sets `reviewed_by` and `approved_by` to `userId()` automatically
- `print.php` displays signatory names from `reviewed_by` and `approved_by` joins
- `view.php` also shows signatory info
- The `gas_vouchers` table already has `reviewed_by` and `approved_by` columns (user IDs)

## Changes Required

### 1. `pages/gas-vouchers/approve.php` — Add Signatory Selector

**Backend changes:**
- Fetch list of active motorpool head users for the review step dropdown
- Fetch list of active Chief Admin & Finance users for the approval step dropdown
- On POST, read `reviewed_by` or `approved_by` from form submission instead of `userId()`

**Frontend changes:**
- Add a `<select>` dropdown before the decision buttons
- For Step 1 (Review): "Select Reviewer" dropdown listing all active `ROLE_MOTORPOOL` users
- For Step 2 (Approval): "Select Approver" dropdown listing all active `ROLE_CHIEF_ADMIN_FINANCE` users
- Default selection to the current user if they match the role
- Make it required before submitting

**SQL for fetching signatories:**
```php
// Motorpool heads (for reviewed_by)
$motorpoolHeads = db()->fetchAll(
    "SELECT u.id, u.name FROM users u 
     WHERE u.role = ? AND u.deleted_at IS NULL AND u.is_active = 1 
     ORDER BY u.name",
    [ROLE_MOTORPOOL]
);

// Chief Admin & Finance (for approved_by)
$chiefFinanceUsers = db()->fetchAll(
    "SELECT u.id, u.name FROM users u 
     WHERE u.role = ? AND u.deleted_at IS NULL AND u.is_active = 1 
     ORDER BY u.name",
    [ROLE_CHIEF_ADMIN_FINANCE]
);
```

### 2. `pages/gas-vouchers/view.php` — No changes needed
Already joins `reviewed_by` and `approved_by` to users table and displays names.

### 3. `pages/gas-vouchers/print.php` — No changes needed
Already joins and displays signatory names. Falls back to hardcoded defaults if empty.
