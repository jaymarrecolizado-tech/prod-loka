HOW THESE FILES ENABLE MOBILE RESPONSIVENESS
=============================================================================

- Defines breakpoints at 576px, 768px, 992px
- Hides sidebar on mobile by default

- Makes tables scrollable horizontally on mobile
- Stacks cards vertically on mobile
- Adjusts chart sizes for mobile screens

JavaScript (app.js):
- Detects mobile view (window.innerWidth < 992px)
- Toggles sidebar with overlay on mobile
- Collapses sidebar on desktop

- Remembers desktop sidebar state
- Initializes all responsive components
